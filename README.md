# Gaby Modas — Site Intitucional

Site responsivo desenvolvido para uma loja de acessórios femininos, com foco em apresentação de produtos, identidade visual e experiência do usuário.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Destaques

- Layout responsivo
- Interface voltada para comércio
- Organização visual de produtos
- Interações com JavaScript

## 🎯 Objetivo

Projeto prático para aplicar conceitos de desenvolvimento front-end e transformar uma proposta visual em uma página funcional.

## 🚀 Demonstração

Projeto publicado na Vercel.
